# T1.6 コマンド（抽出・提案・評価を通しで回す）

- 状態：未着手
- 段：1　依存：T1.4

## 目的
人が1つのコマンドで、接続 → 抽出 → 提案 → 検証 → 評価を回せるようにする。

## やること
- `mandara` コマンド（Application 層）：`extract`（カタログ → 主張）、`propose`（主張 → OM）、`validate`、`eval`、通しの `run`
- 範囲（スキーマ）の指定。接続情報は環境変数
- 実行の記録（入力のハッシュ、版、提案数）を `work/<source>/runs/` に書く（仕様 6.3、6.6.5）

## 完了条件
- AW に対して `run` が通り、OM・主張・評価・実行の記録が `work/adventureworks/` に出る
