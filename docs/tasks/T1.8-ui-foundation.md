# T1.8 UI の土台

- 状態：未着手
- 段：1　依存：なし

## 目的
オントロジーUI とレビュー画面が乗る土台を作る。見た目の方向（エヴァのコンソールルーム、SF のオペレーションルーム）をここで決める。

## 背景
決定（2026-10-15）：TypeScript + React + Vite、MapLibre GL、Cytoscape.js。Python はローカルの HTTP API（FastAPI）。境界の契約は OM ファイルと JSON。仕様 9.1、9.4。

## やること
- Python の HTTP API（Application 層の上の薄い入口）：OM の一覧・表の取得
- TS の型を①から生成（LinkML の `gen-typescript`）し、手で型を二重に書かない。生成物の食い違いを検査する
- React + Vite の骨格。`ui/` に置く
- 見た目：配色、文字、パネル、グリッド、動きの方向を決め、トークン（CSS 変数）にする。案を2〜3出して選んでもらう
- 別言語の出力は信頼できない入力として、受け取る側で検証する（CLAUDE.md）

## 完了条件
- API から正解 OM を取得して画面に出せる
- 型の生成と食い違い検査が CI 相当のテストで回る

## 決めること
- 見た目の方向（案から選ぶ）
- UI のビルド・依存管理（npm / pnpm）
