# T1.9 オントロジーUI v0

- 状態：完了（2026-10-15）
- 段：1　依存：T1.8

## 目的
OM を人が一目で把握できる形で出す。最初の「動いて見える」もの。

## 背景
仕様 9.4（OM → UI の既定対応）。

## やること
- 全体図：表をノード、関係をエッジにしたグラフ（Cytoscape.js）。関係型で線種を変える（is-a、part-of、classified-as、has、辺）。エンティティグループで色分け
- 表の詳細：表種別、grain、主キー、列（ドメイン、単位、enum の値とラベル）、関係
- 状態（proposed / approved / rejected）と確信度が見える
- 正解 OM と自動生成した OM の両方を開ける

## 完了条件
- 正解 OM の 14 表が全体図と詳細で見える

## 実装で決めたこと
- グラフ（Cytoscape.js）：表がノード、表の間の関係と中間表の辺がエッジ。線の形と色は関係型ごと（ui/src/vocabulary.ts の表。①から生成した enum で網羅を型で強制）、辺は太い破線とラベルを重ねる。ノードの枠の色はエンティティグループ（6 色を巡回、凡例に出す）、提案中は点線、却下は薄く
- 表の詳細：種類、粒度、レビューの状態と確信度、主キー・代替キー、列（ドメイン、enum の値とラベル、単位）、関係（相手へ移動）、辺
- 参照先の解決と結合の表し方は graph.ts に1つだけ置き、グラフと詳細の両方が使う。解決できなければ隠さずにエラーを出す
- URL（?ontology=…&table=…）で、見ている OM と表を表す（開き直し・共有で同じものが見える）。無い ID は明示する
- 一覧の行はボタン（キーボードで選べる）。グラフはキーボードで操作できないので、一覧を代わりの手段として案内する
- 法則テスト：Python が生成した文書すべてで、ノード・エッジの対応、ID の一意、端点の実在、型・状態の保存、self、辺の向き
