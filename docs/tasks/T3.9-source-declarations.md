# T3.9 ソースの宣言（既定の通貨）

- 状態：完了
- 段：3　依存：T3.7

## 目的
データやカタログからは分からないソースの性質を人が1回宣言し、推論の根拠にする。最初は金額の通貨。

## 背景
AdventureWorks には通貨の手がかりが無く、判断モデルは金額の単位に「分からない」と答える。単位の要る意味型は単位が無いと
検証（UNIT_MISSING）を通らないので、金額の列が意味型ごと落ち、ドメインビューワで合計が出なかった。仕様 6.6.2（主張の出所）。

## 決めたこと（2026-10-18 合意：案 1）
- 宣言は work/<source>/declarations.yaml（SourceDeclarations。①で定義）。`mandara declare --source S --default-currency USD` で書く
- 抽出のたびに、範囲内の表ごとの主張 amounts_in（source.kind: declaration、確信度 1.0）にする。台帳は丸ごと作り直すが、宣言はファイルに残る
- 単位の問いで、金額の列にだけ「持ち主の宣言：行が別の単位を言わない限り USD」を事実として添え、宣言の主張を根拠に入れる。
  規則で決め打ちはしない（通貨コードの列がある表では、判断モデルがそちらを選べる）
- 宣言できる通貨は ①の Unit のうち通貨（USD、JPY）だけ。手で書き換えた不正な宣言は読む境界で拒む
