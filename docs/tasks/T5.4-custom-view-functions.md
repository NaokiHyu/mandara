# T5.4 カスタム表示関数（LLM に書かせる）

- 状態：未着手
- 段：5　依存：T5.1, T2.5

## 目的
カスタム UI を「ドメインのデータを受け取って React コンポーネントを返す関数」として差し替えられるようにし、その関数を LLM に書かせる。既定は素朴なドメインエディタ風の表示でよい。

## 背景
- 仕様 9.4 の `display/<table>.yaml` の `overrides`、9.5 のビルダー、9.7（OM の変更で上書きが壊れたら CI で検出）
- 入力が狭く型があるので、LLM が書きやすい。大袈裟な仕組みにしない
- 集合と個を分ける（2026-10-16 の提案）
  - 集合（A ドメイン。表に相当）：インスタンスの検索 UI を含む。検索結果のインスタンスが実際のデータ
  - 個（A ドメインのインスタンス。行に相当）：1件の詳細
  - 検索の UI は OM から組める（enum の列 → 絞り込み、日付 → 期間、n:1 の先 → 検索つきの選択）

## やること
- インスタンスの TS 型を OM から生成する（`ui/src/om` と同じ生成の流れ）
- 表示関数は2種：集合（検索の条件と結果 → コンポーネント）、個（インスタンス → コンポーネント）
- `overrides` に書いた関数があればそれで表示し、無ければ既定の表示
- LLM に型と見本のインスタンスを渡して関数を書かせる

## 完了条件
- AdventureWorks の 1 表で、LLM が書いた集合と個の表示関数に差し替えて表示できる
