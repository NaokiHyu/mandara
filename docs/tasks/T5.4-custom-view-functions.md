# T5.4 カスタム表示関数（LLM に書かせる）

- 状態：未着手
- 段：5　依存：T5.1, T2.5

## 目的
カスタム UI を「ドメインインスタンスを受け取って React コンポーネントを返す関数」として差し替えられるようにし、その関数を LLM に書かせる。既定は素朴なドメインエディタ風の表示でよい。

## 背景
- 仕様 9.4 の `display/<table>.yaml` の `overrides`、9.5 のビルダー、9.7（OM の変更で上書きが壊れたら CI で検出）
- 入力が狭く型があるので、LLM が書きやすい。大袈裟な仕組みにしない

## やること
- インスタンスの TS 型を OM から生成する（`ui/src/om` と同じ生成の流れ）
- `overrides` に書いた関数があればそれで表示し、無ければ既定の表示
- LLM に型と見本のインスタンスを渡して関数を書かせる

## 完了条件
- AdventureWorks の 1 表で、LLM が書いた表示関数に差し替えて表示できる
