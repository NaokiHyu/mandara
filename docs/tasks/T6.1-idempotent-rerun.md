# T6.1 冪等な再実行

- 状態：未着手
- 段：6　依存：T1.6

## 目的
再実行で差分だけを提案し、人の判断を上書きしない。

## 背景
仕様 6.5、6.3（approved / rejected を上書きしない）

## やること
- ソースが変わらなければ提案は出ない
- rejected はソースが変わらない限り再提案しない

- 改名の追跡：モデラー v0 の ID は存在の場所のハッシュなので、改名すると変わる。既存の OM と突き合わせて ID を引き継ぐ（仕様 4.2、15.2）
- 今の write_ontology は人の判断を1つでも含む OM を上書きしない。判断を保ったまま差分を統合する

## 完了条件
- 法則テスト：2回目の実行で提案が増えない。承認済みが変わらない
