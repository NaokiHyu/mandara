# T7.1 外の世界の知識でデータを増やす

- 状態：未着手（2026-10-18 に積んだ。重いので仕様の章から始める）
- 段：7（フェーズ 2）　依存：T3.6（再生成できない主張の保存）

## 目的
AI が OM の文脈に応じてインターネットや外部の API から知識を取りに行き、良さそうなものを出所つきの主張として提案する。
人のレビューを通ったものはオントロジーに入る。例：住所 → 位置（ジオコーディング）、店舗名 → 住所・位置・写真。

## 背景（2026-10-18 の相談）
- 主張の出所の種類 `world` は仕様にある（6.6.2）。外から得た事実は、出所（URL・API）、取得日（valid_at）、確信度つきの主張にし、
  ほかの提案と同じくレビューに通す
- 中間 DB が要る。2 つに分ける：
  - 主張の置き場（再生成できない主張。T3.6 の保存方針そのもの）
  - 取ってきた中身の置き場（写真、ジオコーディングの応答など。KVS 的な動的な DB）。Mandara はデータを持たない（ゼロコピー）
    原則の例外になるので、仕様で例外の範囲を決める

## 決めること（仕様の章として下書きしてから）
- 何を取りに行ってよいか：意味型ごとに許す取得（住所 → ジオコーディング、など）を宣言し、そこから広げる。自由な徘徊はしない
- 個人：pii の列・人の表は既定で対象外。人の名前から顔写真を探して結び付けることはしない（プライバシー、同意、取り違え）
- 同名の取り違え（同じ名前の別の店）：確信度と根拠、レビュー
- 費用・上限・取得元の利用規約・鮮度（取り直し）
- 最初の題材：ジオコーディング（住所の列 → 位置の提案。地図にすぐ出る）
